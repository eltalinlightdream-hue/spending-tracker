# Spending Tracker

A tiny personal finance app that tracks daily spending and builds weekly and
monthly reports as tables, bar charts, pie charts, and line graphs.

- **Fully offline** — all data is stored on your device (localStorage). No server, no account.
- **Two currencies** — Uzbek so'm (UZS) or US dollar (USD), chosen on first launch and changeable in Settings.
- **Reports** — week and month views with total, daily average, category breakdown, and monthly summary.
- **Backups** — export your data as JSON (restorable) or CSV (opens in Excel).
- **Installable** — works as a home-screen app on iPhone and as a regular web page on computers.

## Use it

Open the GitHub Pages link for this repository in any browser.

**On iPhone:** open the link in Safari → tap the Share button → **Add to Home Screen**.
It gets its own icon and works offline after the first visit.

**On a computer:** just open the link, or install it via the browser's install button.

## Notes

Data is stored per device — the phone and the computer each keep their own list
(that's the trade-off for working with no internet). Use *Settings → Download
backup* to move data between devices.
